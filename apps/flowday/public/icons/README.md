# Iconos PWA

`icon-192.png` e `icon-512.png` (referenciados por `public/manifest.json`) son un
placeholder generado por `apps/flowday/scripts/generate-icons.mjs` (marca "fd" sobre el
color de marca `#4f46e5`) — regenerar con `node scripts/generate-icons.mjs`. Pendiente del
sistema de diseño real (§C-5.2 `brand.ts` no fija valores de marca definitivos); reemplazar
estos dos archivos cuando exista un ícono diseñado, sin tocar `manifest.json`.
